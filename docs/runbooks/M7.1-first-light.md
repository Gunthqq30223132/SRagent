## GĐ1 — Protocol (PICO) — chốt bởi CON NGƯỜI trước khi tìm kiếm

```bash
.venv/bin/python tools/protocol_build.py \
  --topic "tổng hợp công nghệ RAG: cơ chế, đánh giá, tích hợp hệ thống" --draft-llm
# → in đường dẫn tools/protocols/<slug>.json
```

**BƯỚC NGƯỜI (bắt buộc, không được bỏ)**: mở file protocol, sửa `population`/
`intervention` + synonyms tiếng Anh cho sát ý định, rà `exclusion_criteria`
(mặc định ET1–ET5, ET7). Protocol sau khi sửa là BẤT BIẾN của lần chạy này.

## GĐ2 — Ingest thật (Identification)

```bash
.venv/bin/python tools/protocol_build.py \
  --render tools/protocols/<slug>.json --sources arxiv,ieee --run
.venv/bin/python -m sr_agent.pipeline status   # dán output: đếm theo status
```

Kỳ vọng: `fetched ≥ 20`, có `duplicates` (D34 làm việc), có `rejected_by_rubric`
(gate 60 làm việc), `queued ≥ 5`. Nguồn IEEE lỗi 403 → kiểm tra lại API key; arXiv
lỗi mạng → chạy lại 1 lần (tenacity đã retry sẵn).

## GĐ3 — Screening kép (PRISMA Screening) — số liệu QUAN TRỌNG NHẤT của First Light

```bash
.venv/bin/python tools/screen_run.py --protocol tools/protocols/<slug>.json --limit 20
```

Dán nguyên văn: số doc processed, **Cohen's κ**, số escalated. Đối chiếu:
- κ = None kèm lý do single_model → tag model B sai/chưa pull (quay lại GĐ0).
- κ < 0.6 → alert SCREEN_DISAGREEMENT sẽ mở — GHI NHẬN, không chỉnh gì (dữ liệu
  hiệu chuẩn M7.2 cần chính con số thô này).

## GĐ4 — Extraction có minh chứng (chỉ doc còn queued)

```bash
.venv/bin/python tools/evidence_extract.py --limit 10
```

Kỳ vọng: grounding score per-doc; field quote bịa → verified=0 + event
`EXTRACT_UNVERIFIED` (đây là firewall hoạt động ĐÚNG, không phải lỗi).
